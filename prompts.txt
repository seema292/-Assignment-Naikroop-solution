Prompt Specification 1: Architecture & Core Form Builder Setup
--------------------------------------------------------------------------------
"Build a production-grade, document-style form builder web application inspired by Tally.so for the Naikroop Solutions frontend assessment using React 19, TypeScript, Tailwind CSS, and Vite.
Requirements:
- Notion/Tally-like document editor canvas where users build forms by typing and adding blocks.
- Left block palette / slash insertion with categorized blocks.
- Real-time right-hand properties inspector for selected block configurations (label, placeholder, required toggle, validation rules, helper text).
- Debounced autosave mechanism (600ms) with saving/saved indicators.
- Schema-driven JSON form structure with stable unique block IDs.
- Client-side persistence using a defensive localStorage service with initial seed forms."

Prompt Specification 2: Form Block Registry (13+ Dynamic Blocks)
--------------------------------------------------------------------------------
"Implement a comprehensive block registry supporting 13 distinct block types:
1. Heading Block (H1, H2, H3 sizes with optional subtitle)
2. Paragraph Block (rich instructional text)
3. Short Text Input (single line with placeholder & required validation)
4. Long Text Area (multiline expandable textarea)
5. Email Input (RFC-compliant regex email validation)
6. Number Input (numeric validation with min/max constraints)
7. Multiple Choice (single selection radio group)
8. Dropdown (custom select dropdown)
9. Single Checkbox (consent / agreement confirmation)
10. Multiple Checkboxes (multi-select option list)
11. Date Picker (HTML5 date input with min/max bounds)
12. Star Rating (interactive 1-5 or 1-10 star rating component)
13. Submit Button (custom button text, color, and alignment controls)"

Prompt Specification 3: Dashboard & Form Management
--------------------------------------------------------------------------------
"Create a comprehensive dashboard page (`/`):
- Metric stats overview cards: Total Forms, Published Forms, Total Responses.
- Search bar to filter forms by title.
- Status filters (All, Published, Draft).
- Form cards with preview metadata, response count badge, and creation timestamp.
- Actions: Edit Form, Preview Form, Copy Public Share Link, Duplicate Form, and Delete Form (with confirmation modal).
- Empty state with CTA to create a new form."

Prompt Specification 4: Dual-Purpose Dynamic Form Renderer & Public View
--------------------------------------------------------------------------------
"Implement a unified `DynamicFormRenderer` component used across Preview and Public Form Submission:
- Responsive multi-device preview emulator (`/preview/:id`) with Desktop, Tablet, and Mobile viewport frames.
- Public respondent form page (`/forms/:id`) with clean, distraction-free document layout.
- Double-submission lock to prevent accidental multiple submissions.
- Form validation error alerts and inline field error states.
- Friendly submission success screen with response confirmation."

Prompt Specification 5: Submissions Analytics & Response Viewer
--------------------------------------------------------------------------------
"Build a submissions viewer page (`/forms/:id/submissions`):
- Submissions summary counter and submission timeline.
- Clean tabular view displaying all submitted fields and timestamps.
- JSON data export feature allowing users to download collected responses.
- Ability to delete individual submissions."

Prompt Specification 6: Internationalization (i18n - English & Hindi)
--------------------------------------------------------------------------------
"Integrate bilingual internationalization using `i18next` and `react-i18next`:
- Complete UI translations in English (`en`) and Hindi (`hi`).
- Header language switcher with persistent language preference in localStorage.
- Localized date formatting using native `Intl.DateTimeFormat`.
- Localized number formatting using native `Intl.NumberFormat`.
- Decouple interface translation from user-created form schemas so content remains authentic."

Prompt Specification 7: Visual Polish & SaaS Enhancements
--------------------------------------------------------------------------------
"Enhance visual aesthetics and UX for production quality:

- Quick-start pre-made template shelf (e.g., Customer Feedback, Event Registration, Contact Inquiry).
- Rich SaaS footer with branding, feature list, stack summary, and assessment attribution.
- Smooth Tailwind CSS transitions, micro-interactions, and focus rings."
